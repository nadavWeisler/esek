```python
def from_score(t_score: float, sample_size: int, confidence_level: float = 0.95) -> OneSampleTResults:
    """
    Calculate one-sample t-test effect sizes from a t-statistic.

    Parameters
    ----------
    t_score : float
        The t-statistic from the one-sample t-test.
    sample_size : int
        Total number of observations (N). Must be ≥ 2.
    confidence_level : float, optional
        Desired confidence level for interval estimates (default 0.95).
        Must be in (0, 1).

    Returns
    -------
    OneSampleTResults
        cohens_d : CohenD
            Cohen's d effect size with central, pivotal, and non-central CIs.
        hedges_g : HedgesG
            Hedges' g (bias-corrected Cohen's d) with CIs.
        t_score : float
            The input t-statistic (echoed for convenience).
        degrees_of_freedom : int
            Degrees of freedom (N − 1).
        p_value : float
            Two-tailed p-value (capped at 0.99999).

    Notes
    -----
    Cohen's d is computed as:

    .. math:: d = \\frac{t}{\\sqrt{N-1}}

    Hedges' g applies the bias-correction factor J (Hedges, 1981):

    .. math:: g = J \\cdot d, \\quad J = \\frac{\\Gamma(\\frac{df}{2})}{\\sqrt{\\frac{df}{2}} \\cdot \\Gamma(\\frac{df-1}{2})}

    References
    ----------
    Cohen, J. (1988). *Statistical Power Analysis for the Behavioral Sciences* (2nd ed.).
    Hedges, L. V. (1981). Distribution theory for Glass's estimator of effect size. *Journal of Educational Statistics, 6*, 107–128.

    Examples
    --------
    >>> from esek.calculator.one_sample_mean import OneSampleTTest
    >>> result = OneSampleTTest.from_score(t_score=2.5, sample_size=30)
    >>> print(f"Cohen's d = {result.cohens_d.value:.3f}")
    Cohen's d = 0.463
    >>> print(f"95% CI = [{result.cohens_d.ci.lower:.3f}, {result.cohens_d.ci.upper:.3f}]")
    95% CI = [0.098, 0.821]
    """
```

## Rules
- **Never invent formula descriptions** — derive from source code comments and standard references
- Effect size names must match their canonical academic names (e.g., "Cohen's d", not "cohens_d")
- Cite the original paper (APA style) in every Notes section that describes a formula
- Every Examples section must have working, copy-pasteable Python code
- For the CI methods in Proportions, always name the method (e.g., "Wilson score interval")
- Magnitude interpretation labels: small / medium / large per Cohen (1988) thresholds
